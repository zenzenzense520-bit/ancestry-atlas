# Primary sources and open-source references

| Source | Use |
| --- | --- |
| [PLINK 2 resources](https://www.cog-genomics.org/plink/2.0/resources) | Full public Phase 3 GRCh37 PGEN, PVAR and PSAM files |
| [IGSR Phase 3](https://www.internationalgenome.org/data-portal/data-collections/phase3/) | Original release and assembly context |
| [Official sample panel](https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/release/20130502/integrated_call_samples_v3.20130502.ALL.panel) | ID, population and superpopulation verification |
| [IGSR population definitions](https://github.com/igsr/1000Genomes_data_indexes/blob/master/README_populations.md) | Reference population codes |
| [plink-ng](https://github.com/chrchang/plink-ng) | pgenlib decoding and independent PLINK CLI cross-check |
| [peddy](https://github.com/brentp/peddy) | Earlier sparse baseline and coordinate panel cross-check, MIT license |
| [Ensembl variation API](https://grch37.rest.ensembl.org/documentation/info/variation_id) | Archived public coordinate anchors |
| [NCBI RefSNP](https://api.ncbi.nlm.nih.gov/variation/v0/refsnp/3748595) | Independent archived coordinate evidence |
| [Fontsource Noto Serif SC](https://github.com/fontsource/fontsource) | Font distribution; Noto font remains SIL OFL, subsets renamed |
| [Observable Plot](https://github.com/observablehq/plot) | Layered scientific chart and legend inspiration, ISC license |
| [Lenis](https://github.com/darkroomengineering/lenis) | Motion/reading rhythm inspiration, MIT license |

The HTML uses native controls and calculated Matplotlib SVGs. Observable Plot and Lenis are design references, not runtime dependencies. This project does not claim an Awwwards, Webby Awards or FWA award. Download manifests preserve actual URLs, lengths and hashes in the local research package.

Public database snapshots contain reference variant coordinates, not the user's genotype calls. Their upstream terms continue to apply. Original code is MIT-licensed; the license does not override data, font or third-party terms.
